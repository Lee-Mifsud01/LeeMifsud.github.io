MCAST Mobile App

This project is a mobile application concept focused on simple navigation, clear screen layouts, and a user-friendly experience. The aim of the project was to design an app that presents useful information in a clean and organised way.


Project Overview

The mobile app was designed to organise important information into clear and easy-to-read sections. The project focuses on mobile usability, visual hierarchy, spacing, and making each screen simple for the user to understand.



Key Features

  • Mobile-first interface design
  • Clear home screen layout
  • Calendar section
  • Internship information section
  • Timetable screen

Design Process

The design process focused on making the app easy to use on a smaller screen. Each screen was planned with clear spacing, readable content, and simple navigation. This helped the app feel less crowded while still presenting the user with useful information.

What I Learned

This project helped develop a better understanding of mobile UI design, especially how layout, spacing, and visual consistency affect the user's experience. It also showed the importance of designing screens that are simple, direct, and easy to follow.
