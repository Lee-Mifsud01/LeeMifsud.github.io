GPU Vortex

A technology-focused website concept built around product browsing, strong visual hierarchy and a clean user journey. The project is presented as a polished ecommerce-style experience rather than a static website exercise.

Project overview

Turning a simple site into a believable product experience.

GPU Vortex presents gaming hardware through organised pages, strong imagery and a clear browsing structure. I focused on making each page feel connected, so users can move from the homepage to product information without the design feeling confusing or unfinished.

Clear navigation Product sections Consistent branding Responsive layout
Design direction

Less classroom project, more digital storefront.

The page design uses large screenshots, layered cards and floating notes to show the project in a more professional way. Instead of placing every explanation in equal boxes, the content now moves like a portfolio case study with moments for context, features and visual evidence.

01

Structure

I planned the website around important user actions: landing on the homepage, understanding the brand, viewing products and finding contact information.

02

Visual hierarchy

Large images, short text blocks and clear section titles help the project feel easier to scan while still showing the design choices behind it.

03

Interaction

Clickable screenshots, hover motion and modal previews make the case study feel more interactive and suited to a digital interactive media portfolio.
