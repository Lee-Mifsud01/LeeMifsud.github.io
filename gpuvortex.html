Website, UI/UX

GPU Vortex

This project is a responsive website focused on clear structure, strong visual layout, and a simple user experience. The aim of the project was to create a polished website that is easy to navigate and visually consistent across different pages.



Project Overview

The website was designed to present information in a clean and organised way. The project focuses on layout, navigation, spacing, responsive design, and creating a consistent visual style across the full website.



Key Features

  • Responsive page layout
  • Modern navigation structure
  • Consistent visual style
  • Product and content sections
  • Clean UI design

Design Process

The design process focused on creating a website that looks professional while remaining simple to use. Attention was given to image placement, spacing, readability, and page structure so that the final design feels clear and easy to follow.
